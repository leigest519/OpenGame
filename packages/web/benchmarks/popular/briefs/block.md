制作原创小游戏《方块港湾》，借鉴 Block Blast 的方块拼放核心玩法，使用自己的港口配色与几何图形，不使用原作名称、商标、素材或代码。中文界面，面向电脑与手机，一局可以不断挑战最高分。不要套用射击或堆叠三消模板。

规则：8×8棋盘，每轮提供3个不可旋转的不同形状方块；玩家先选手牌，再点棋盘作为左上角放置。方块必须全部在棋盘内且不重叠。放置后同时清除所有满行和满列，交叉格只清除一次；放置按格数得分，每条消除线额外10分。手牌全部用完再补充3个。仅当所有剩余手牌在棋盘任何位置均放不下才判负，不能因为当前选中的一块放不下就结束。失败后停收放置输入，重新开始完全清空分数、棋盘和选中状态。

请加入公开可选的教学局：棋盘最后一行前7格已填满，第一块手牌为单格；玩家在最后一格放入后正常走同一个规则模块完成消行。不要自动通关或隐藏测试入口。正式模式默认空棋盘随机手牌。

界面要有可见的当前分数、消除行列累计、剩余手牌、错误放置提示。棋盘格用真实可访问按钮，标签包含第几行第几列；手牌按钮展示形状，支持键盘和触屏点击。在窄屏和电脑全屏都完整显示棋盘及操作区，开始游戏、重新开始必须可用。需要 Phaser 主画面，DOM操作按钮与游戏共用状态。

规则独立放在 src/rules.ts，界面只调用这一套规则；模块不依赖DOM、Phaser或网络，导出清楚的初始化、落子、合法位置检测和死局判断接口，方便后续复用和独立验收。参数集中配置，更新项目记忆、设计和模块记录；测试未经外部执行不得写成已通过。
