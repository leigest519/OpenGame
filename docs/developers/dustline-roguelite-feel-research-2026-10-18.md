# 《废土列车》爽感改版研究

调研日期：2026-10-18。范围：官方产品说明、开发者发布页与公开源码；未以玩家攻略、评价或二手销量估算作为机制证据。以下明确区分已核验事实与本项目设计建议，建议数值不是原作数值。

## 结论

以 **Vampire Survivors（吸血鬼幸存者）作为本轮主要参考**：学习“杀敌→吸取经验→立即三选一→武器形态成长→成群收割→精英奖励与进化”的正反馈。保留废土列车的驾驶、车厢和三地区 Boss 身份。SNKRX 继续提供列车式移动的适配依据，Brotato 仅用于检查波次与商店节奏，不把三款的全部系统一起堆进来。

这是一项设计判断：用户需要更强的能力增长和战场回报，而上一轮主要增加地图、敌种与复杂 Boss，增加内容和压力不保证增加爽感。具体缺陷仍须结合现版本代码、实际操作验证，不能仅凭此研究断言。

## 下一版可直接执行的原创设计

以下均为设计提案，不是对原作的逐项复刻；不复制角色、美术、音乐、物品名或文案。

### 1. 先建立一分钟内的成长曲线

- 开场直接配备一门强弱清晰的连射机炮和低频近身冲击，初始就能打出命中、击退、碎裂和拾取。
- 普通杂兵以 1–3 次命中击杀为目标，不依赖玩家开技能才能清理；精英负责承压，杂兵负责收割。
- 第一轮升级目标 8–12 秒，首分钟 4–6 次升级；中段约每 15–25 秒一次，后段不因等级需求暴涨而停止成长。
- 将敌群安排为“铺量→可清理密集群→短喘息→精英”循环。约 70% 为脆弱杂兵，其余承担包抄、远程或防御功能；不要同时给所有敌人加血和加速。
- 三地区保留，但取消每小波强制商店；只在击败地区 Boss 后停靠。战斗时间暂停时，刷新、冷却、拾取移动和增益计时一起暂停。

### 2. 把掉落升级为持续的经验循环

- 杂兵必掉经验能源，精英掉更多；废料仍是商店货币，经验和货币视觉及结算分开。
- 列车任意车厢经过均能吸引，避免自动前进的车头被迫精确掉头捡豆；吸引距离初始约 110–140 世界单位，进入吸引后持续追随。
- 经验不因常规短生命周期消失。数量上限时合并邻近经验球并保留总量；离屏远点保留紧凑记录，不销毁玩家劳动。
- 加入低频全屏吸取补给；升级、开箱、Boss 转场前后检查一次性结算，多个升级入队，不能溢出丢经验。

### 3. 三选一需要改变打法和画面

升级时自动暂停，显示三张有明确效果的卡片。第一轮至少有一项进攻提升；卡片显示当前等级、变化、进化搭配，过滤已满级和没有适用武器的死选项。固定 1/2/3 或点选，恢复时清空旧键，避免技能键同时触发。

首批升级建议：额外弹道、穿透、弹跳电弧、爆炸范围、冷却缩短、燃烧地带、环绕防御、拾取半径。伤害加成可保留，但不应占满选择。第二次选择后应能肉眼辨识与开局的不同。

### 4. 三条进化路线比十种浅技能更重要

| 原创路线             | 可见的基础成长               | 达标后的质变                                     |
| -------------------- | ---------------------------- | ------------------------------------------------ |
| 机炮 Lv.4 + 弹链组件 | 单弹→双弹→穿透→更短间隔      | 风暴转轮：连续扇形穿透火线，弹道明显增多         |
| 电弧 Lv.4 + 电容组件 | 跳跃目标数、范围逐步提高     | 雷暴网络：跨敌连接，并周期释放区域电网           |
| 烈焰 Lv.4 + 燃料组件 | 喷射变宽、地面残火、持续伤害 | 熔炉尾迹：列车经过形成燃烧带，并触发受控连锁爆破 |

精英宝箱在条件满足时优先提供进化，未满足时明确显示缺少条件并给有效升级；不能让首次质变只能靠极小概率。目标是认真选同一路线的玩家在约 90–150 秒内看到一次进化。配方持续可查，后续选择池适度支持已选路线；不保证每次随机都能立即凑齐。

### 5. 击杀必须被看到、听到

- 命中：短促闪白、微击退、少量方向性碎片；不同武器有差异音色，音频需由用户交互解锁。
- 击杀：短碎裂/爆破、经验弹出后吸入、拾取音阶；击杀计数与短连杀提示不遮挡行车。
- 暴击、精英击杀、进化有更强但有限的冲击环和镜头反馈。普通每发子弹不全屏震动，不给每个杂兵全局停顿。
- 命中停顿若加入，仅用于低频重大事件，总量受限；持续驾驶尤其要防止停顿破坏转向手感。
- 设置里可以关闭震动、降低粒子并静音。敌人红色预警必须始终盖在己方华丽效果之上。
- 超载技能可以在短时间内密集清场，但 Boss 应有可见减伤/控制抗性；不要让普通敌人的击退同样无限锁住 Boss。

## 实施优先级与验收

P0：经验循环、三选一、前三次成长清晰、密集低血杂兵、命中/击杀/拾取反馈。
P1：三条进化、精英箱、全屏吸取、地区商店节奏。
P2：在前述验证后再增加敌人与技能数量，避免稀释本次改版。

必须验证：

1. 真实驾驶下首分钟至少出现四次可兑现选择，不能只靠测试直接改经验；记录首杀、首升级、各级时间与击杀数。
2. 三种进化均有真实可达配方，进化前后不是只换名字，分别测试新增弹道、连锁目标、持续区域伤害。
3. 经验球合并前后总值守恒，重复碰撞只记一次；一次吸取跨多级仍逐次选择；暂停、转场、重开不存在丢经验或重复发奖。
4. 三选一不会提供三张满级或无效卡；暂停状态没有敌人偷袭，恢复无按键残留；A/D/空格/E 和中文输入法回归。
5. 摄像机、多屏、三 Boss 的弱点与胜利流程保留；玩家造成的爆炸不会遮蔽 Boss 预警。
6. 记录高密度战斗的帧时间、对象上限、音效并发；在目标窗口大小实际驾驶并检查画面，不以模型宣称替代验收。

这些指标验证功能与节奏，不能证明每位玩家都会觉得爽。最终需要实际玩首分钟和至少一条完整进化路线；若只做自动测试，应明确其局限。

## v3 实际基线与本轮实施

检查线上第三版 `2a4bdcf1-8118-4dbe-9aba-c4da20255f8d` 的发布产物：初始为机枪车+盾车，只有机枪输出；没有战斗内经验升级；普通机枪索敌距离340、生成半径720、车速185、基础追击敌速58。每普通航段32秒后商店。以上为源码事实，不是原作游戏数据。

用线上同一引擎、种子1–5、不开主动技能采样前30秒：直行12–15杀，恒定缓转26–29杀，首杀约2.25–10.45秒。脚本见 `output/wasteland-train/feel-baseline.cjs`，原始结果见 `output/wasteland-train/v3-feel-baseline.json`。这只验证固定路径的战斗密度，不代表真人技巧或趣味评价。

本轮已向线上 Studio 提交实现任务，采用 Vampire Survivors 为主要参考。首升8–12秒、首分钟至少3次有效选择作为初步验收目标，4–6次作为进一步调优目标；仍需新版真实引擎实测，而不是在报告中视作已达成。

## 第四版交付与独立核验

线上第四版：`e52c4d25-525a-47cf-80c2-6d4077e772f0`。已实现九种基础强化、三个进化、经验晶体合并、整列吸取、升级暂停、1/2/3选卡、宝箱、全场经验吸取器、连杀过载，以及区域Boss后商店。实际进化配方采用两种关联强化各达到2级，再选对应进化（取代提案中的武器Lv.4配方）。

使用生产bundle进行独立确定性核验（`output/wasteland-train/v4-feel-check.cjs`）：经验合并总量、重复拾取保护、选卡冻结、超额经验、三条进化攻击差异、三个Boss奖励/升级/商店或胜利顺序、重开与中文实体键映射均通过。机炮进化实测7道穿透弹，电弧进化有11跳及范围爆发，火焰进化留下持续燃烧区域。

种子1–5、三种固定转向、每次选首张卡、不放主动技能的前60秒样本：首次升级约8.48–14秒，完成4–5次选择。与v3相同直行样本的前30秒击杀从12–15变为162–173。这个比值只代表固定样本战斗密度，不代表“爽感提高多少倍”，且开场样本均存活，后段挑战仍需真人体验调优。

种子4、固定缓转、优先选指定路线，正常击杀获取经验（不注入经验）的180秒样本：风暴机炮约58.85秒、电弧约76.6秒、熔炉约158.47秒获得进化；三条路线均推进到第二地区。完整数据见 `output/wasteland-train/v4-natural-evolution.json`。没有宣称这是完整人工通关。

## 第五版纠偏：高击杀不等于好手感

用户实玩反馈第四版过强、看不见怪。重新使用实际引擎测可见敌人数与首次可见到死亡的时间：种子1–3缓转前60秒，第四版平均可见4.66/6.77/6.68只，寿命中位0.67/0.90/0.95秒；种子1空屏19.6%。单因素试验表明降低基础电弧伤害最有效，单独改变射程或生成半径改善有限。

第五版 `7d900288-2a92-4b5d-b349-7d69e48c3e50` 将基础电弧降至10伤害、1.2秒间隔，机枪/电弧射程375/310，限制范围成长与不可见目标，敌人放大并添加鲜明配色，生成考虑镜头/整列安全距离，增益持续6秒且有间隔。经验需求同步下调。

对生产产物独立复测：上述三个种子平均可见13.75/10.16/8.52只，寿命中位1.63/1.48/1.22秒，空屏均约1.75%，每分钟升级4次。第二个样本有实际受伤（90HP）；这是固定输入的功能与节奏采样，不代表完整难度平衡。脚本与原始数据位于 `output/wasteland-train/enemy-visibility-check.cjs`、`v4-visibility.json`、`v5-visibility.json`。输入、升级暂停、经验、三进化、Boss结算和重开回归均通过。
