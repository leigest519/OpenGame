# 手动体验 AI 创作：热门小游戏候选

核验日期：2026-10-15。本轮重新读取官方游戏平台、开发商支持中心与官方商店，补充上一轮 Block Blast、Suika、Crossy Road 之外的方向。本报告用于用户亲自操作制作流程；没有创建平台项目、生成游戏或修改产品代码。

## 结论

建议本次先选 **Level Devil 式的五关原创平台跳跃**：规则容易说清，首版内容可控制，玩过之后也容易提出“跳跃舒服一点”“陷阱提前给提示”“把第三关变简单”等具体修改。备选是 **Color Block Jam 式滑块解谜**和 **Hole.io 式 2D 吞噬成长**。这是依据首版范围和迭代难度作出的产品判断，不是热度排名。

- Poki 的热门页是该平台当前展示的热门集合；没有公开全球全平台榜单，也不把展示顺序当作精确排名。下文点赞和投票数均是读取时的累计计数。[Poki 热门页](https://poki.com/en/popular)
- Google Play 的 `10M+` 等数字为累计下载档位，不是月下载、活跃用户或当前全球排名。所读页面为英文界面；语言参数不证明榜单地区，故不将页面偶见的类别榜名次写成美国或全球排名。
- 动态商店页、搜索摘要和设备分栏的评价数量可能不同。下表采用直接打开页面的顶部计数，仅作量级依据；推荐时优先引用下载档位。更新日期只能证明近期维护，不能证明近期下载增长。
- 玩法参考与首版规格分开记录：首版的主题、关卡数、时间和规则简化是本次原创设计建议，不冒充原作内容。

## 推荐的手动制作起点

### 1. 《出口别捣乱》：首选

第一版只做中文 2D 单屏平台跳跃，主角用原创小机器人，目标是到达出口。五关依次引入普通跳台、踩后延迟塌陷、周期移动尖刺、会移动的平台，最后一关只组合已学会的两种机关。每关有明显起点和终点；失败约半秒后能重试；支持方向键、空格及触屏按键，完整通关后能重开。

把“意外”留给机关变化，同时保证重试后能理解并应对；不需要复制原作关卡或视觉。开局先讨论“希望搞笑还是偏技巧”，只选一种风格，再开始实现。

第一轮亲手验收：能否不看说明就开始；第一关是否顺利；死一次后是否知道原因；第三关是否明显过难；重开是否把机关和角色一起复位。第二轮只改一个问题，例如给塌陷地板加入短暂抖动提示，并明确保留原有移动速度和其他关卡。

### 2. 《彩箱归位》：适合偏好思考和触屏操作

第一版做三色方块与同色出口，6×6 棋盘、五个原创可解关卡、拖动预览、撤销与重开；先不加倒计时。用户重点体验“拖起来顺不顺”“卡住时知道为什么吗”“是否存在无法完成的局面”。第二轮可添加一步提示，或让用户自己描述一关，观察平台能否正确理解与验证。

### 3. 《口袋清理队》：适合先感受爽感

第一版用原创 2D 小镇和可移动清理口，90 秒一局，吞掉小物体增加体积，最后能吞大型物件；明确标示当前可吞的东西。先用固定小地图和单人计分，结束后可以立即再玩。第二轮只调整成长节奏、吸入动画或物体主题，比较体验变化。

## 本次流程边界

本次由用户自己在 OpenGame 描述需求、开始实施、试玩和提出修改。研究只提供候选与可复制的规格思路，不提前替用户创建项目、提交生成或发布。首次不同时加入广告、内购、联网对战、排行榜和完整美术资产库，以便看清聊天、任务展示、制作、反馈这一回路是否顺畅。

用户试玩后最有价值的记录是：原始描述、第一次实际感受、一个明确的修改要求、修改后是否改善，以及原有玩法有没有退步。热门作品提供选题信号，不能替代对我们生成作品的实际体验。
