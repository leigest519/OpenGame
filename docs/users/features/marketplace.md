# 作品广场、评价与访问量

作品广场位于 `/marketplace`，从工作台导航或访问码登录页进入。页面公开展示所有成员已发布游戏的标题、简介、好评率和访问次数，未发布草稿不会出现。公开介绍可被搜索引擎收录；试玩、评价、项目编辑、对话及源码仍需要受邀登录，编辑操作仍限定作品作者。

试玩页提供点赞和差评按钮。每个账号对每款游戏只保留一个评价，可以切换评价，再次点击当前评价即可取消。本机个人模式共用一个本机评价身份。好评率为点赞数除以总评价数并四舍五入为整数百分比；没有评价时显示“暂无评价”。

访问量按成功打开游戏页面计数，不是独立访客数。重新打开或刷新页面增加一次，游戏内重开和页面内重新载入游戏不增加。重复发送同一个页面访问标识不会重复计数。评价与访问记录存入数据库，随工作台备份保留。新版本发布不会清空游戏累计统计。

广场由服务器直接输出 HTML，提供 canonical、Open Graph、允许索引的 robots 元数据。`/sitemap.xml` 列出广场，`/robots.txt` 提供站点地图并排除私有入口。其他应用页面默认 noindex。生产构建必须使用实际 `OPENGAME_APP_ORIGIN` 和 `OPENGAME_PREVIEW_ORIGIN`，同时设置 `OPENGAME_ACCESS_MODE=invite`，避免站点地图出现本机地址。完成配置不保证搜索引擎立即收录。

部署需要更新源码和正式构建，重新启动服务以自动创建评价与访问表。只修改本地文件不会更新线上页面。
